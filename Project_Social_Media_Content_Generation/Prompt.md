### 📋 The RICE POT Prompt

**Copy the text below:**

> **Role:**
> Act as a Senior AI Automation Architect and B2B Content Strategist specializing in the software testing and QA domain.
>
> **Instructions:**
> 1. Design a fully automated, daily LinkedIn posting workflow utilizing "vibe coding" (natural language programming) and low-code/no-code frameworks.
> 2. Detail the exact tool stack required to build this automated pipeline, explicitly covering tools for:
>    * **Orchestration/Integration:** (e.g., Make.com, n8n, or Zapier)
>    * **Content Generation:** LLMs accessible via API (e.g., Google Gemini, NVIDIA NIM)
>    * **Image Generation:** (e.g., Midjourney, DALL-E 3, or Leonardo AI)
>    * **Publishing:** LinkedIn API or scheduling tools.
> 3. Generate a 5-day sample batch of highly engaging, 100% unique LinkedIn posts ready to be published. Each post must focus on the intersection of QA, Software Testing, Automation testing tools, and AI.
> 4. For each day's post, include a highly detailed, cinematic image generation prompt that matches the content.
>
> **Context:**
> The goal is to build an automated daily LinkedIn presence without daily manual intervention. The content must appeal to QA professionals, software developers, and tech leaders. The setup should be completely "vibe coded"—meaning it relies on natural language instructions to stitch together APIs and AI models to handle the end-to-end process of ideation, drafting, image creation, and posting.
>
> **Example:**
> * **Workflow Step Example:** [Trigger: Every day at 9 AM] ➔ [Action: Gemini API generates QA post] ➔ [Action: DALL-E 3 generates image] ➔ [Action: Make.com posts to LinkedIn].
> * **Content Example:** "Is generative AI the end of manual testing? Not quite. Here are 3 ways AI models are actually augmenting QA workflows today..." (Include appropriate formatting, bullet points, and hashtags).
> * **Image Prompt Example:** "A cinematic, ultra-realistic image of a glowing digital magnifying glass hovering over glowing lines of software code, neon blue and orange lighting, 8k resolution, photorealistic."
>
> **Purpose:**
> To establish consistent, high-quality thought leadership in the QA and AI automation space while leveraging cutting-edge API integrations to eliminate the manual workload of content creation and publishing.
>
> **Output:**
> 1. A clear, step-by-step architecture map of the automated workflow.
> 2. A definitive list of the recommended tools required to build this vibe-coded system.
> 3. 5 ready-to-share LinkedIn posts (including emojis, spacing, and hashtags).
> 4. 5 corresponding image generation prompts.
>
> **Tone:**
> Professional, authoritative, innovative, and highly actionable. The content should be engaging and spark conversation among tech professionals.

### 🛠️ How this prompt works for your goals

* **Targeted Content:** The instructions specifically lock the AI into your core domains: QA, Software Testing, and AI.
* **Vibe Coding Focus:** It explicitly instructs the AI to design the system using low-code/no-code APIs (like NVIDIA NIM or Gemini) that can be stitched together with natural language prompts.
* **Actionable Tool Stack:** The prompt forces the AI to output the exact orchestration platforms and APIs needed to make the automation a reality.
