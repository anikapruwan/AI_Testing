# Automated LinkedIn Content Pipeline — QA × AI

Daily LinkedIn posts about QA, software testing, and AI — generated by Command Code, illustrated by Google Imagen, published via Buffer (with Upload-Post fallback). Zero daily manual effort.

## Architecture

```
cron / systemd timer (daily 9 AM)
        │
        ▼
  run_daily.sh
        │
        ▼
  content_pipeline.py
        │
        ├──[1]── cmd -p → Command Code generates post + image prompt (JSON)
        │
        ├──[2]── Google Imagen → gemini-2.5-flash-image (free tier)
        │         generates cinematic image from prompt
        │
        └──[3]── Buffer GraphQL API → createPost mutation → LinkedIn
                   │ (fails? falls through)
                   └── Upload-Post.com → upload_text → LinkedIn
```

All providers use a **fallback chain** — if one fails, the next one catches it automatically.

## Quick Start

### Prerequisites

```bash
npm i -g command-code && cmd login   # Content generation brain
pip install pyyaml certifi           # Python dependencies
```

### 1. Configure

```bash
cd output/pipeline
cp config.yaml config.local.yaml
```

Fill in your credentials in `config.local.yaml`:

| Key | Where to get it |
|-----|----------------|
| `publishing.buffer.access_token` | [buffer.com/developers/apps](https://buffer.com/developers/apps) → Create App → Access Token |
| `publishing.buffer.profile_id` | Run `GET https://api.buffer.com/` GraphQL query for your LinkedIn channel ID |
| `publishing.upload_post.api_key` | [upload-post.com](https://upload-post.com) dashboard → API key |
| `image_generation.google_imagen.api_key` | [aistudio.google.com](https://aistudio.google.com) → API keys |

### 2. Test

```bash
# Dry run (content only, no publishing)
python3 content_pipeline.py --dry-run config.local.yaml

# Full run (content + image + publish)
python3 content_pipeline.py config.local.yaml
```

### 3. Schedule

```bash
# systemd timer (recommended)
sudo cp linkedin-poster.service linkedin-poster.timer /etc/systemd/system/
sudo systemctl enable linkedin-poster.timer
sudo systemctl start linkedin-poster.timer

# Or cron
0 9 * * * /path/to/pipeline/run_daily.sh --config=/path/to/config.local.yaml
```

## Providers

### Publishing (fallback chain)

| Order | Provider | Method | Free? |
|-------|----------|--------|-------|
| 1 | **Buffer** | GraphQL `createPost` mutation | Free tier |
| 2 | **Upload-Post.com** | REST `upload_text` | Free tier |

### Image Generation

| Provider | Model | Cost |
|----------|-------|------|
| **Google Imagen** | `gemini-2.5-flash-image` | Free tier (rate limited) |

Switch providers or reorder them anytime by editing the `providers:` list in your config.

## Content Customization

Edit `config.local.yaml` to control what gets posted:

```yaml
content:
  max_chars: 1300            # Max post length
  hashtag_count: 8           # Total hashtags per post
  fixed_hashtags:            # Always included
    - QAAutomation
    - SoftwareTesting
    - AIinTesting
  domains:                   # Topic pool (random pick each day)
    - QA Automation
    - AI in Software Testing
    - Self-healing Test Frameworks
    - API Testing with LLMs
    - Career Growth in QA
```
